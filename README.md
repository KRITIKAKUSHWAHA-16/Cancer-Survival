# Cancer Survival Analysis Using R

## Project Overview
This project investigates cancer patient survival using statistical methods in R. It applies Kaplan–Meier survival estimation and Cox proportional hazards regression to explore survival patterns and factors associated with patient outcomes.

## Objectives
- Estimate overall survival using Kaplan–Meier methods.
- Compare survival distributions between patient groups.
- Identify prognostic factors using Cox proportional hazards regression.
- Evaluate model discrimination and performance.

## Statistical Methods
- Descriptive statistics
- Kaplan–Meier survival analysis
- Log-rank test
- Cox proportional hazards regression
- Hazard ratios and 95% confidence intervals
- Model performance assessment

## Tools and Technologies
- R
- RStudio
- survival
- survminer
- ggplot2
- dplyr

## Project Files
- `R.R` — R analysis script
- `CANCER-CELL.html` — HTML report
- `README.md` — Project documentation

## Purpose
This project demonstrates practical application of survival analysis techniques relevant to epidemiology, biostatistics and clinical research.
